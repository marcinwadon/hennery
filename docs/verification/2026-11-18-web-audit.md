# Unpatched build-tool advisory

GHSA-fc5q-39xc-vjpf (CVE-2026-112366) was updated on 2026-11-17 to
cover picomatch through 4.0.7. The npm registry has no patched version as of
2026-11-18. References:

- https://github.com/advisories/GHSA-fc5q-39xc-vjpf
- https://github.com/micromatch/picomatch/pull/194

The vulnerable repeated-extglob parser can backtrack exponentially on an
attacker-supplied pattern. Hennery uses picomatch only through development
tools: Vite, Vitest, their plugins and test integrations. These tools consume
repository-controlled build/test patterns; the package is absent from the
production frontend dependency graph and both managed adapter locks. The
collector serves built static assets and does not execute this Node tooling
on operator input. This is an exposure assessment, not an upstream fix.

Until 2026-12-02, `packaging/audit_web.py` accepts only this advisory for
picomatch 4.0.7, with every finding marked dev-only and every path rooted in
the enumerated development tools. It rejects new/production paths, other
advisories, available patched versions, registry errors and incomplete reports.
The unmodified raw audit report, including the high finding, remains in release
evidence. Routine CI, daily audit and release preparation share this policy;
there is no global package-manager ignore or production-audit exclusion.

Remove this exception and update the lockfile as soon as a patched version is
available. The fixed expiry blocks future qualification until reassessment.
