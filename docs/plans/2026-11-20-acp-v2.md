Implementation rulings:

- Use raw JSON-RPC driver at the version boundary with typed validation for
  changed v2 contracts; preserve raw notifications and v1 actor catalogue types.
- Preserve managed-adapter steering: if v2 omits existing steering, automatic
  mode restarts with v1 before session creation; strict v2 refuses explicitly.
  Do not misrepresent queued v2 prompts as immediate steering injection.
- V2 entities have session-wide IDs. Persist immutable pre-update seeds at each
  entity's first event in a display group, alongside untouched raw events, to
  reconstruct paginated/live/resumed views with bounded memory.
- Page boundaries are explicit and independent of entity origin groups; clients
  retain the newest version when an entity appears in multiple page groups.
- After a storage I/O stall and operator restart, compile with at most two jobs,
  run tests with at most two threads, and run heavy commands sequentially.
