# Project picker (plan 6c) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ] `) syntax for tracking.

**Goal:** The New-session form can pick a project on a host (ACP core §7, §9; frontend §7; umbrella §1.2):
- **Workspace roots** are configured on the host, in `host.toml` or with `--workspace-root`, and reported in `hello`. The collector stores them on the host's row once the connection is reconciled.
- **`list_projects`** enumerates the git repositories under the roots, bounded, and says when a bound cut it short. The collector caches it for 60 s, per owner, host and connection.
- **`browse_directory`** lists the subdirectories of an absolute path that lies, after symlink resolution, under a workspace root or the user's home.
- **Two routes**, `GET /api/hosts/{id}/projects` and `GET /api/hosts/{id}/browse?path=`, answer from the host's probes. They go only to a host with the `projects` capability.
- **Recents:** the directory a session started or resumed in becomes one of its host's recent projects, under the hat it resolves to; the picker shows the recents of the hat the browsing path resolves to now (kernel §5.3).
- **The probe map:** a non-outboxed request/reply mechanism in the hub, scoped to the connection, shared with hats' `resolve_path` (plan 5b), under the names agreed with that lane.
- The API only. The frontend is plan 4's.

**Architecture:**
- **Wire** (`hennery-proto`):
  - `frames.rs`: `list_projects`, `browse_directory`; their replies `projects` and `directory`; `hello.workspace_roots`; `HostFrame::probe_request_id`, exhaustive.
  - `paths.rs` (new): `is_within`, the one path-segment rule, for the fence now and hat rules later.
  - `rest.rs`: `HostItem.workspace_roots`, `HostProjects`, `RecentProject`, `DirectoryListing`. The schema and TypeScript files are regenerated.
- **Host** (`hennery-host`):
  - `projects.rs` (new): the roots and home; the enumeration; the fence and its listings; `Probes`, which runs them on blocking threads, bounded.
  - `identity.rs`: `host.toml`'s `workspace_roots`, kept when a re-pair rewrites the file.
  - `connection.rs`: `HostConfig.workspace_roots` and `home`; the roots in `hello`; the two probes answered; `projects` announced.
- **Collector**:
  - `hennery-sessions/src/hub.rs`: the probe map (`probe`, `probe_reply`, `probe_rejected`), `RequestError::Unsupported` and `Busy`, `routable_conn`.
  - `hennery-sessions/src/ws.rs`: one `probe_reply` arm; a host `error` answers its probe first; the roots stored at reconciliation; a recent remembered on an applied `session_started`.
  - `hennery-sessions/src/projects.rs` (new): the two routes and `ProjectsCache`.
  - `hennery-kernel`: migrations 7 and 8 (`hosts.workspace_roots`, `project_recents`; 6 and 7 when this plan was written, renumbered after hats 5a's migration 6); `Hosts::record_workspace_roots`, `is_displayable_path`, `is_displayable_text`; `recents.rs` (new), `Hosts::remember` and `Hosts::recents`, which joins the owner-filter audit's `SOURCES`.
- **CLI** (`hennery`): `--workspace-root` on `host run` and on `up`, which hands it to its host child.

**Tech Stack:** Rust (edition 2024, MSRV 1.88), rusqlite 0.40 (bundled SQLite), tokio, axum 0.8, toml 1.1. No new crates: `Cargo.lock` does not change.

## Decisions this plan makes where the spec is silent

These were confirmed by a stronger-model security review on the maintainer's behalf (2026-10-01, "approve after amendments"), before any code was written: the code below is built to the amended decisions. Each gives the choice, the alternatives, and the cost if it is wrong. Items marked **(amendment)** depart from explicit spec text and should be written back into it.

**What the review changed:**
- A1: a path that does not canonicalise is judged by its longest ancestor that does. Outside the fence it is `outside_workspace`, whether it exists or not; only inside does the answer say why (decision 3).
- A2: the `.`/`..` check reads the path string itself, since `Path::components` drops an inner `.` and merges `//` (decision 3).
- A3: a listing is of the canonical path; a symlinked entry and its `git` flag are judged by what it resolves to (decision 4).
- A4: the host runs probe work on blocking threads, never in the connection loop, at most one enumeration and four listings at once; one more is answered `busy`; a listing has a time budget too (decision 5).
- A5: `Hub::probe` checks the capability, and the probes in flight, on the connection it sends on, under the hosts lock (decision 1).
- A6: the collector checks every string a host sends back: known error codes only, with its own messages; paths, `home` and entry names displayable; counts bounded (decision 2).
- A7: only the enumeration is cached; recents are read afresh, so plan 5's hat filter is never served from a cache keyed by host. Both routes check in the same order (decisions 10, 11).
- A8: the hand-off to hats is widened ("After this plan").
- A9: one canonicalisation (`projects::canonical`) and one segment rule (`hennery_proto::paths::is_within`), byte for byte, for the fence now and for `resolve_path` and hat rules later (decision 3).
- A10: `$HOME` counts only when it is absolute; without it, `home` is absent, the fence is the roots alone, and a `~/` root is refused (decisions 6, 8).
- Optional hardening taken: O3 (at most 8 probes in flight per connection), O5 (`Cache-Control: no-store`), O6 (an error reading `.git` is "not a repository"). O9 holds already: `host.toml` is written with the existing atomic 0600 writer.
- Not taken: O2 (store capabilities at reconciliation too): `host join`'s probe announces the same constant capabilities as `host run`, so nothing is lost, and an existing test pins the version recorded on `hello`. O1, O4, O7 and O8 are recorded in "After this plan".

1. **The probe map: connection-scoped, timed out without a drop.**
   - **Choice:**
     - `Hub::probe(&self, host_id, request_id, frame, timeout) -> Result<HostFrame, RequestError>`, the shape agreed with the hats lane. A separate `probes` map, keyed by request id, each entry holding the `conn_id` it went out on; not the session waiters.
     - Under the hosts lock, then the probes lock (the waiters' order): the connection must be reconciled, have the frame's capability (`RequestError::Unsupported`), and have fewer than `MAX_PROBES` (8) probes in flight (`RequestError::Busy`, O3); then the entry is inserted and the frame sent on that connection (A5).
     - `ws.rs` routes `projects` and `directory` with one `probe_reply` arm (hats adds `resolved_path` to it). A reply on another connection, late, or never asked for is logged and dropped. A host `error` answers a probe of the same connection before the session waiters see it.
     - **A timeout answers `DeliveryUnknown` and keeps the connection.** ACP core §3.4 drops a connection whose request timed out so that the next handshake reconciles it; a probe changes no state, so there is nothing to reconcile. Its 15 s is also below the 45 s read deadline, which the state-changing requests' assert requires of them, not of probes.
     - The entry is removed by a drop guard, so a probe whose HTTP handler is gone is gone too; no watchdog. `unregister` fails the connection's probes.
     - `HostFrame::probe_request_id` is an exhaustive match: a new host frame must say whether it is a probe reply, or nothing compiles (umbrella §5.4). The host's `handle` and the socket's reader are exhaustive matches already.
   - **Alternatives:** probes as waiters (`CompletedBy::Probe`): the waiters' timeout drops the connection, and their answer type is a `SessionBody`. A watchdog per probe, as for waiters: a guard does the same without a task.
   - **Cost if wrong:** a host that never answers probes keeps its connection and costs each caller 15 s; `MAX_PROBES` bounds what it can pile up.
2. **The routes' answers when no listing comes back.**
   - **Choice:**
     - Both routes check, in order: the host is the owner's (404 `not_found`); connected and reconciled (409 `host_offline`); it has `projects` (409 `projects_unsupported`; nothing is sent, as `park_unsupported`). Then the cache, then the probe (A7).
     - A probe that times out, or whose connection drops: 503 `no_answer`. `MAX_PROBES` reached, or the host says `busy`: 503 `busy`.
     - A host refusal with a code the collector knows: decision 3's status, with the collector's own message. Any other code, a reply of the wrong kind, or a listing of a path that cannot be shown: 502 `bad_reply` (A6). The host's message is never shown.
     - Paths (`items[].path`, `home`, `path`, `parent`) must be `is_displayable_path`: absolute, at most 4096 bytes, no control or Unicode format character. An item or a parent that fails is left out; a listing whose own path fails is `bad_reply`. Entry names must be plain (no `/`, not `.` or `..`, not empty), at most 255 bytes, displayable. At most 16 000 items (500 per root, 32 roots) and 1000 entries; past them the answer is marked partial or truncated.
     - Both answers carry `Cache-Control: no-store` (O5).
   - **Alternatives:** 504 for a probe timeout: hennery's other answers are 503 for a host that did not deliver (`delivery_unknown`), but that code says a state change may have happened, which a probe never makes; `no_answer` says what happened.
   - **Cost if wrong:** codes the frontend has not been written against yet.
3. **The browse fence and its refusals.** (amended after the security review of 2026-10-01: A1, A2, A9)
   - **Choice:**
     - The collector refuses a `path` that is missing, not absolute, longer than 4096 bytes, or holds a control character: 400 `invalid`, the host not asked.
     - The host refuses a path that is not absolute, or holds a `.`, `..` or empty segment (one trailing `/` aside), read from the string (A2): `invalid` (400).
     - The path is canonicalised on the host (`projects::canonical`: `std::fs::canonicalize`, as UTF-8). The fence is every workspace root and the home directory, each canonicalised when the probe runs (a root made since counts; a missing one is left out). The path must be within one by whole segments, byte for byte (`is_within`, A9): `/home/u` never admits `/home/u2`, and case is never folded.
     - Outside: `outside_workspace` (403). A path that does not canonicalise is judged by its longest ancestor that does (A1): outside, `outside_workspace`; inside, the I/O error's own code. So `root/link-to-etc/passwd` and `root/link-to-etc/nope` answer alike.
     - Inside: `path_not_found` (404), `not_a_directory` (400), `permission_denied` (403), any other I/O error `unreadable` (502).
   - **Alternatives:** a lexical check of a missing path against the roots: the review's A1 showed it is an existence oracle through a symlink. Walking with `openat` and `O_NOFOLLOW` per component (O7): stronger against a race, recorded; an agent on the host runs as the same user and can read anything anyway (umbrella §8.4).
   - **Cost if wrong:** the fence keeps the operator from wandering by accident; it is no defence against a hostile collector, which can start a session in any cwd.
4. **A listing: directories only, dot-entries hidden.** (amended after the security review of 2026-10-01: A3)
   - **Choice:** the subdirectories of the canonical path, sorted by name, at most 1000 (then `truncated`), from at most 10 000 entries read within 5 s (then `truncated`). A symlink is listed when it resolves to a directory inside the fence, under its own name, with the `git` flag of its target; one pointing out, or to a file, is left out. Dot-entries, non-UTF-8 names and names with a control character are left out. `git` is set when the directory holds `.git`, a directory or a file (a worktree). `parent` is the canonical parent when it is inside the fence.
   - **Alternatives:** files too: a picker of working directories has no use for them. Dot-directories listed: `.git`, `.cache` and the like are noise; one can still be browsed by typing its path.
   - **Cost if wrong:** the frontend shows less than a file manager would; nothing more leaks than names of directories inside the fence.
5. **The enumeration's bounds.** (amended after the security review of 2026-10-01: A4)
   - **Choice:**
     - Repositories at most 4 levels below a root (the root itself counts). This depth defines the enumeration and does **not** set `partial`: with `$HOME` as a root it would always be set, and mean nothing.
     - Per root: 500 repositories (ACP core §7) and 10 000 directories visited; 5 s for the whole enumeration, every root together, well below the collector's 15 s. Any of these sets `partial`.
     - Symlinks are not followed, so a link cannot lead out or round in a loop; a root that is a symlink is resolved and walked where it leads. Dot-directories are skipped. A repository is not looked into (submodules, nested repositories and vendored ones are not listed). Unreadable directories are skipped. Each directory's children are walked in sorted order, so the same tree gives the same answer, bounds included. Results are sorted and deduplicated across overlapping roots.
     - `Probes` runs the enumeration and every listing on blocking threads (`spawn_blocking`), at most `MAX_LISTS` (1) and `MAX_BROWSES` (4) at once; one more is answered `busy` at once (A4). It outlives each connection, so the bounds hold across reconnects. A reply goes out on whatever connection is up when it is ready; another connection's reply is dropped by the collector (decision 1).
   - **Alternatives:** a time bound alone: not testable, and a huge directory would still fill memory; the visit bound caps the queue too. A depth that sets `partial`: see above.
   - **Cost if wrong:** repositories deeper than 4 levels are found only by browsing to them.
6. **Workspace roots: the file's, or the flags', which replace them.** (amended after the security review of 2026-10-01: A10)
   - **Choice:**
     - `host.toml` gains `workspace_roots = ["/abs", "~/rel"]`. `hennery host run --workspace-root <path>` (repeatable) and `hennery up --workspace-root <path>`, handed to its host child, **replace** the file's list when given, as `--listen` replaces `config.toml`'s (kernel §2: flags > file).
     - Each root is absolute, or `~` / `~/…` expanded against `$HOME` when that is absolute (A10); otherwise the start fails with a message naming the root. At most 32 roots; duplicates are dropped; a missing root is kept (tolerated, ACP core §7). Checked before the host connects.
     - `hennery host join`, re-pairing after a revoke, rewrites `collector` and `host_id` in the parsed `host.toml` and keeps every other key; a `host.toml` that does not parse is an error, never replaced. The file is still written atomically, mode 0600.
   - **Alternatives:** flags that add to the file: the precedence of kernel §2 says otherwise, and adding cannot remove a root from the command line. An environment variable: not needed for v1.
   - **Cost if wrong:** an operator with roots in `host.toml` who passes one flag loses the file's roots for that run, by design.
7. **The roots reported as configured, and stored only from a reconciled connection.** **(amendment)** to kernel §4.3.
   - **Choice:** `hello.workspace_roots` carries the roots as configured, expanded, not canonicalised. The collector stores them on `hosts.workspace_roots` (kernel migration 6) when the connection's `resend_complete` has been reconciled, before the host is marked ready. `hennery host join`'s standing probe sends a `hello` that knows nothing of `host run`'s flags and never reaches `resend_complete`, so it cannot wipe them. Capabilities and the version are still recorded at `hello`, as before. At most 32 roots are stored, each `is_displayable_path`; others are dropped with a warning. `HostItem` lists them.
   - **Alternatives:** at `hello` (kernel §4.3's words): a re-run `host join` would wipe them. The probe sending `host.toml`'s roots: still wrong for a host run with flags.
   - **Cost if wrong:** the stored roots trail a host that connects and never reconciles, which is a host that cannot be used anyway.
8. **`home` in the projects answer.** (amended after the security review of 2026-10-01: A10)
   - **Choice:** the `projects` reply and `HostProjects` carry `home`, the host's canonical `$HOME`, absent when there is none, so the picker can expand `~` (frontend §7). Browse stays absolute-only (ACP core §7). `HostConfig.home` is injectable, so no test reads the real home.
   - **Alternatives:** `browse_directory` accepting `~/…`: ACP core §7 says absolute only. `home` in `hello`: one more field stored for one use.
   - **Cost if wrong:** the single operator sees the host's home path, which umbrella §8.3 already lets them see.
9. **`projects` announced by every host.**
   - **Choice:** the host announces `projects` beside `park`, also with no roots: browsing under home works.
   - **Cost if wrong:** none known.
10. **The cache: the enumeration only, per owner, host and connection.** (amended after the security review of 2026-10-01: A7)
    - **Choice:** `ProjectsCache` keeps `(items, partial, home)` by `(owner_id, host_id)`, with the `conn_id` it was filled from, for 60 s (`CACHE_TTL`, injectable). It is served only while that connection is the host's routable one, and every owner's entry for a host is dropped when the host registers a new connection. An offline host is answered `host_offline`, never from the cache. Errors, listings and recents are never cached.
    - **Alternatives:** keyed by host alone: one owner's enumeration served to another. Serving an offline host from the cache: its roots may change before it returns, and it cannot start a session anyway.
    - **Cost if wrong:** a new repository shows up to a minute late; a reconnect refreshes it at once.
11. **Recents, per hat, shown for the hat a path resolves to now.** (amended after hats 5a merged and the scoped review of 2026-10-02: A1–A3)
    - **Choice:**
      - Kernel migration 8: `project_recents(owner_id, host_id, hat_id, path, last_used_at, PRIMARY KEY(host_id, hat_id, path))`, kernel §1.1's key. Its host and hat are the owner's by composite foreign keys, as hat rules' are, with `ON DELETE CASCADE`: recents are derived, so a later purge or host removal cannot fail on them or forget them (the review's optional cascade, taken).
      - **The write:** `ws.rs` remembers the session's stored cwd when an **applied** `session_started` is ingested, of a start or a resume; a duplicate or a stale one creates no `session_started` event. It runs after the ingest commits and before the ack; a failure is logged, never fatal: recents are not state.
        - Only a cwd that is canonical (`hats::is_canonical`) and displayable is remembered: until hats 5b resolves it on the host, it is what the client sent.
        - Its hat is `Hosts::resolve_hat(host, cwd)`. Hats 5c, which stores `sessions.hat_id`, switches the write to that.
        - `start_session` is not touched.
      - **The read** (kernel §5.3): `GET /api/hosts/{id}/projects?path=`.
        - `path` is checked before anything else: at most 4096 bytes, no control character, canonical; else 400 `invalid` (the review's A2).
        - With `path`, the hat is the one `path` resolves to; without it, the host's default hat. The answer names it (`recents_hat_id`).
        - `Hosts::recents(host, hat, limit)` reads the host's recents and keeps those whose path resolves to that hat **now**, against the host's current rules and default hat (the review's A1). A stored `hat_id` goes stale when a rule or the default changes, and would show one hat's project in another's recents.
        - A path stored under two hats is shown once, with its latest use.
      - 50 kept per (host, hat), pruned on each write; the 20 newest shown, read afresh on every request (A7). No `hat=` parameter.
      - `items`, `partial` and `home` are not filtered by hat, and stay cached: the operator sees every hat (umbrella §8.3); recents are the listed side channel.
    - **Alternatives:**
      - filtering by the stored `hat_id`: A1's leak;
      - no recents without a `path`: the picker would open empty, and the host's default hat is the only hat an absent path resolves to;
      - a host round trip to resolve `path`: that is 5b's `resolve_path`.
    - **Cost if wrong:** before 5b, a cwd reached through a symlink (`/tmp/x` while a rule says `/private/tmp`) can be filed under the default hat. Once paths are canonical, A1 corrects it by itself.
12. **The answers' shapes.**
    - **Choice:** `GET /api/hosts/{id}/projects` → 200 `HostProjects { recents: [{path, last_used_at}], items: [{path}], partial, home? }`, `last_used_at` RFC 3339. `GET /api/hosts/{id}/browse?path=` → 200 `DirectoryListing { path, parent?, entries: [{name, git}], truncated }`. Both behind the operator's session (`operator_only`), no step-up: they change nothing.
    - **Cost if wrong:** routes are cheap to change; the frontend has not been written against them.

/// `connect`, announcing the `projects` capability.
fn connect_projects(hub: &Hub) -> (Registration, mpsc::UnboundedReceiver<CollectorFrame>) {
    let (tx, rx) = mpsc::unbounded_channel();
    let registration = hub
        .register("h", tx, Capabilities(vec![Capability::Projects]))
        .expect("no live connection for h");
    hub.mark_ready("h", registration.conn_id);
    (registration, rx)
}

fn projects(request_id: &str) -> HostFrame {
    HostFrame::Projects {
        request_id: request_id.into(),
        items: Vec::new(),
        partial: false,
        home: None,
    }
}

#[tokio::test]
async fn a_probe_is_answered_only_by_its_own_connections_reply() {
    let hub = Arc::new(Hub::new());
    let (registration, mut rx) = connect_projects(&hub);
    let call = tokio::spawn({
        let hub = hub.clone();
        async move { hub.probe("h", "p1", list("p1"), Duration::from_secs(5)).await }
    });
    assert_eq!(rx.recv().await, Some(list("p1")));
    hub.probe_reply("h", registration.conn_id + 1, projects("p1"));
    tokio::time::sleep(Duration::from_millis(50)).await;
    assert!(!call.is_finished(), "another connection's reply answered the probe");
    hub.probe_reply("h", registration.conn_id, projects("p1"));
    assert_eq!(call.await.unwrap(), Ok(projects("p1")));
    assert_eq!(hub.pending_probes(), 0);
}

pub const MAX_PATH: usize = 4096;

/// The most enumerations, and listings, a host runs at once (the review's
/// A4). One more is answered `busy`.

/// The bounds of an enumeration and a listing (decisions 4 and 5).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Limits {
    /// Repositories kept per root (ACP core §7: 500).
    pub per_root: usize,
    /// How many levels below a root a repository may be. It defines the
    /// enumeration, so it does not make it partial.
    pub depth: usize,
    /// Directories visited per root.
    pub dirs_per_root: usize,
    /// Time for one enumeration, every root together, and for one listing.
    pub budget: Duration,
    /// Entries a listing returns.
    pub entries: usize,
    /// Entries a listing reads, before sorting.
    pub entries_read: usize,
}

impl Default for Limits {

/// The canonical form of `path`: absolute, every symlink resolved, as
/// UTF-8. The one canonicalisation of the fence, for `resolve_path` to
/// share (the review's A9). A path that is not UTF-8 is an error.
pub fn canonical(path: &Path) -> std::io::Result<String> {
    std::fs::canonicalize(path)?
        .into_os_string()
        .into_string()
        .map_err(|_| std::io::Error::new(std::io::ErrorKind::InvalidData, "the path is not UTF-8"))
}

/// The browse fence (ACP core §7): the workspace roots and the home
/// directory, canonicalised when it is built, so a root made since counts
/// and a missing one is left out.
#[derive(Debug, Clone)]
pub struct Fence {
    roots: Vec<String>,
}

impl Fence {
    pub fn new(workspace_roots: &[PathBuf], home: Option<&Path>) -> Self {
        let roots = workspace_roots
            .iter()
            .map(PathBuf::as_path)
            .chain(home)
            .filter_map(|root| canonical(root).ok())
            .collect();
        Self { roots }
    }

    /// Whether the canonical path `path` lies inside the fence, by whole
    /// segments (`is_within`).
    pub fn admits(&self, path: &str) -> bool {
        self.roots.iter().any(|root| is_within(path, root))
    }
}

/// Whether `dir` holds `.git`: a repository, or a worktree of one (whose
/// `.git` is a file). Not followed: a `.git` symlink counts too. An error,
/// such as a directory macOS will not let the host read, is no.
fn is_repo(dir: &Path) -> bool {
    std::fs::symlink_metadata(dir.join(".git")).is_ok()
}

/// `list_projects` (ACP core §7): the git repositories under `roots`,
/// sorted and without duplicates, and whether a bound cut the enumeration
/// short (decision 5). Dot-directories are skipped, symlinks are not
/// followed, and a repository is not looked into. A missing or unreadable
/// root is skipped.
pub fn list_projects(roots: &[PathBuf], limits: &Limits) -> (Vec<Project>, bool) {
    let deadline = Instant::now() + limits.budget;
    let mut found = BTreeSet::new();
    let mut partial = false;
    for root in roots {
        let Ok(root) = canonical(root) else {
            continue;
        };
        partial |= walk(&root, limits, deadline, &mut found);
    }
    (found.into_iter().map(|path| Project { path }).collect(), partial)
}

/// Walk one root breadth first, adding its repositories to `found`. `true`
/// if a bound cut it short.
fn walk(root: &str, limits: &Limits, deadline: Instant, found: &mut BTreeSet<String>) -> bool {
    let mut queue = VecDeque::from([(PathBuf::from(root), 0usize)]);
    let (mut repos, mut visited, mut cut) = (0usize, 0usize, false);
    while let Some((dir, depth)) = queue.pop_front() {
        if Instant::now() >= deadline {
            return true;
        }
        visited += 1;
        if is_repo(&dir) {
            if repos == limits.per_root {
                return true;
            }
            if let Some(path) = dir.to_str() {
                found.insert(path.to_string());
                repos += 1;
            }
            continue;
        }
        if depth == limits.depth {
            continue;
        }
        let Ok(entries) = std::fs::read_dir(&dir) else {
            continue;
        };
        // Sorted, so the same tree gives the same answer, bounds included.
        let mut children = Vec::new();
        for entry in entries.flatten() {
            if entry.file_name().as_encoded_bytes().starts_with(b".") {
                continue;
            }
            // `file_type` does not follow a symlink: a linked directory is
            // not walked into, so a link cannot lead out or round in a loop.
            if !entry.file_type().is_ok_and(|kind| kind.is_dir()) {
                continue;
            }
            if visited + queue.len() + children.len() >= limits.dirs_per_root {
                cut = true;
                break;
            }
            children.push(entry.path());
        }
        children.sort();
        queue.extend(children.into_iter().map(|child| (child, depth + 1)));
    }
    cut
}

/// Why a browse is refused (decision 3): the host's `error` code.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum BrowseError {
    /// Not an absolute path of plain segments.
    Invalid,
    /// Outside the fence, or, if it does not exist, under an ancestor that
    /// is.
    OutsideWorkspace,
    PathNotFound,
    NotADirectory,
    PermissionDenied,
    /// Any other error reading it.
    Unreadable,
}

impl BrowseError {
    pub fn code(self) -> &'static str {
        match self {
            Self::Invalid => "invalid",
            Self::OutsideWorkspace => "outside_workspace",
            Self::PathNotFound => "path_not_found",
            Self::NotADirectory => "not_a_directory",
            Self::PermissionDenied => "permission_denied",
            Self::Unreadable => "unreadable",
        }
    }

    fn message(self) -> &'static str {
        match self {
            Self::Invalid => "give an absolute path without `.` or `..` segments",
            Self::OutsideWorkspace => "the path is outside the workspace roots and the home directory",
            Self::PathNotFound => "no such directory",
            Self::NotADirectory => "the path is not a directory",
            Self::PermissionDenied => "the host may not read this directory",
            Self::Unreadable => "the host could not read this directory",
        }
    }

    /// The refusal for an I/O error on a path inside the fence.
    fn from_io(err: &std::io::Error) -> Self {
        match err.kind() {
            std::io::ErrorKind::NotFound => Self::PathNotFound,
            std::io::ErrorKind::PermissionDenied => Self::PermissionDenied,
            std::io::ErrorKind::NotADirectory => Self::NotADirectory,
            _ => Self::Unreadable,
        }
    }
}

/// A browse's answer: `HostFrame::Directory` without its request id.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Listing {
    pub path: String,
    pub parent: Option<String>,
    pub entries: Vec<DirEntry>,
    pub truncated: bool,
}

/// Whether `path` is absolute and made of plain segments: no `.`, `..` or
/// empty segment (one trailing `/` aside), no control character, at most
/// `MAX_PATH` bytes. Read from the string itself, since `Path::components`
/// drops an inner `.` and merges `//` (the review's A2).
fn is_plain_absolute(path: &str) -> bool {
    let Some(rest) = path.strip_prefix('/') else {
        return false;
    };
    let rest = rest.strip_suffix('/').unwrap_or(rest);
    path.len() <= MAX_PATH
        && !path.chars().any(char::is_control)
        && (rest.is_empty() || rest.split('/').all(|segment| !matches!(segment, "" | "." | "..")))
}

/// `browse_directory` (ACP core §7): the subdirectories of `path`, which
/// must be inside `fence` once canonicalised (decisions 3 and 4).
///
/// - A path that does not canonicalise is judged by its longest ancestor
///   that does: outside the fence it is `outside_workspace`, whether it
///   exists or not; only inside does the answer say why (the review's A1).
/// - The listing is of the canonical path, and each entry is judged by
///   what it resolves to (A3): a directory, or a symlink to a directory
///   inside the fence. Dot-entries, non-UTF-8 names and names with control
///   characters are left out. Sorted by name, at most `limits.entries`.
pub fn browse(fence: &Fence, path: &str, limits: &Limits) -> Result<Listing, BrowseError> {
    if !is_plain_absolute(path) {
        return Err(BrowseError::Invalid);
    }
    let canonical_path = match canonical(Path::new(path)) {
        Ok(found) => found,
        Err(err) => return Err(refusal_below(fence, Path::new(path), &err)),
    };
    if !fence.admits(&canonical_path) {
        return Err(BrowseError::OutsideWorkspace);
    }
    let dir = Path::new(&canonical_path);
    let metadata = std::fs::metadata(dir).map_err(|err| BrowseError::from_io(&err))?;
    if !metadata.is_dir() {
        return Err(BrowseError::NotADirectory);
    }
    let reader = std::fs::read_dir(dir).map_err(|err| BrowseError::from_io(&err))?;
    let deadline = Instant::now() + limits.budget;
    let (mut found, mut read, mut truncated) = (Vec::new(), 0usize, false);
    for entry in reader {
        if read == limits.entries_read || Instant::now() >= deadline {
            truncated = true;
            break;
        }
        read += 1;
        let Ok(entry) = entry else {
            continue;
        };
        let Ok(name) = entry.file_name().into_string() else {
            continue;
        };
        if name.starts_with('.') || name.chars().any(char::is_control) {
            continue;
        }
        let Ok(kind) = entry.file_type() else {
            continue;
        };
        let target = if kind.is_dir() {
            entry.path()
        } else if kind.is_symlink() {
            match canonical(&entry.path()) {
                Ok(resolved) if fence.admits(&resolved) && Path::new(&resolved).is_dir() => PathBuf::from(resolved),
                _ => continue,
            }
        } else {
            continue;
        };
        found.push((name, target));
    }
    found.sort();
    if found.len() > limits.entries {
        found.truncate(limits.entries);
        truncated = true;
    }
    let parent = dir
        .parent()
        .and_then(Path::to_str)
        .filter(|parent| fence.admits(parent))
        .map(str::to_string);
    let entries = found
        .into_iter()
        .map(|(name, target)| DirEntry {
            git: is_repo(&target),
            name,
        })
        .collect();
    Ok(Listing {
        path: canonical_path,
        parent,
        entries,
        truncated,
    })
}

/// The refusal for a path that does not canonicalise: decided by its
/// longest ancestor that does, so an existing and a missing path outside
/// the fence look the same.
fn refusal_below(fence: &Fence, path: &Path, err: &std::io::Error) -> BrowseError {
    let mut ancestor = path.parent();
    while let Some(dir) = ancestor {
        if let Ok(found) = canonical(dir) {
            return if fence.admits(&found) {
                BrowseError::from_io(err)
            } else {
                BrowseError::OutsideWorkspace
            };
        }
        ancestor = dir.parent();
    }
    BrowseError::OutsideWorkspace
}

/// Runs the host's probe work (the review's A4): on blocking threads, never
/// in the connection loop, at most `MAX_LISTS` enumerations and
/// `MAX_BROWSES` listings at once. One more is answered `busy`; the
/// collector says so. The reply goes out on whatever connection is up when
/// it is ready; another connection's reply is dropped by the collector.
#[derive(Clone)]
pub struct Probes {
    lists: Arc<Semaphore>,
    browses: Arc<Semaphore>,
    limits: Limits,
}

impl Default for Probes {
    fn default() -> Self {
        Self::with_capacity(Limits::default(), MAX_LISTS, MAX_BROWSES)
    }
}

impl Probes {
    pub fn with_capacity(limits: Limits, lists: usize, browses: usize) -> Self {
        Self {
            lists: Arc::new(Semaphore::new(lists)),
            browses: Arc::new(Semaphore::new(browses)),
            limits,
        }
    }

    /// Answer `list_projects`: the repositories under `roots`, and `home`.
    pub fn list(&self, uplink: &Uplink, request_id: String, roots: Vec<PathBuf>, home: Option<PathBuf>) {
        let Ok(permit) = self.lists.clone().try_acquire_owned() else {
            uplink.reply(busy(request_id));
            return;
        };
        let (uplink, limits) = (uplink.clone(), self.limits);
        tokio::task::spawn_blocking(move || {
            let _permit = permit;
            let (items, partial) = list_projects(&roots, &limits);
            let home = home.and_then(|home| canonical(&home).ok());
            uplink.reply(HostFrame::Projects {
                request_id,
                items,
                partial,
                home,
            });
        });
    }

    /// Answer `browse_directory` for `path`, fenced by `roots` and `home`.
    pub fn browse(
        &self,
        uplink: &Uplink,
        request_id: String,
        path: String,
        roots: Vec<PathBuf>,
        home: Option<PathBuf>,
    ) {
        let Ok(permit) = self.browses.clone().try_acquire_owned() else {
            uplink.reply(busy(request_id));
            return;
        };
        let (uplink, limits) = (uplink.clone(), self.limits);
        tokio::task::spawn_blocking(move || {
            let _permit = permit;
            let fence = Fence::new(&roots, home.as_deref());

                    entries: listing.entries,

                },
                Err(refused) => HostFrame::Error {
                    request_id,
                    code: refused.code().into(),
                    message: refused.message().into(),
                },
            });
        });
    }
}

        request_id,
        code: "busy".into(),

}

//! Path rules shared by the host's browse fence (ACP core §7) and, with
//! hats, path-rule matching (kernel spec §5.2): one definition, so the two
//! can never disagree (plan 6c, the review's A9).

/// Whether `path` is `root` or lies under it, by whole path segments:
/// `/p/acme` holds `/p/acme` and `/p/acme/x`, never `/p/acme-infra`.
///
/// Both are canonical: absolute, symlinks resolved, no `.` or `..`, no
/// trailing slash (but `/` itself). They are compared byte for byte, and
/// case is never folded: on a case-insensitive filesystem a path spelled
/// differently from its root is outside it, which fails closed.
pub fn is_within(path: &str, root: &str) -> bool {
    if root == "/" {

//! `GET /api/hosts/{id}/projects` and `GET /api/hosts/{id}/browse?path=`,
//! answered by the host's probes, and the enumeration cache.

use crate::api::{error, internal};
use crate::hub::RequestError;
use axum::extract::{Path, Query, State};
use axum::http::{HeaderValue, StatusCode, header};
use axum::response::{IntoResponse, Response};
use axum::routing::get;
use axum::{Json, Router};
use hennery_kernel::hosts::{MAX_ROOTS, is_displayable_path, is_displayable_text};
use hennery_proto::frames::{Capability, CollectorFrame, DirEntry, HostFrame, Project};

/// How long a probe waits for its reply (ACP core §3.4).
pub const PROBE_TIMEOUT: Duration = Duration::from_secs(15);

/// How long an enumeration is served from the cache (ACP core §7).
pub const CACHE_TTL: Duration = Duration::from_secs(60);

/// The most repositories an answer keeps: the host's 500 per root, for
/// every root it may have (the review's A6).
const MAX_ITEMS: usize = 500 * MAX_ROOTS;

/// The most entries a listing keeps (decision 4).
const MAX_ENTRIES: usize = 1000;

/// The longest entry name kept, in bytes.
const MAX_NAME: usize = 255;

/// An enumeration as it is answered and cached: the repositories, whether
/// the host cut it short, and its home directory.
#[derive(Debug, Clone, PartialEq)]
pub struct Enumeration {
    pub items: Vec<Project>,
    pub partial: bool,
    pub home: Option<String>,
}

struct Cached {
    conn_id: u64,
    at: Instant,
    enumeration: Enumeration,
}

/// Enumerations by (owner, host), each served for `ttl`, and only while
/// the host's connection is the one it was filled from (decision 10): a
/// reconnect may bring other roots. Errors and listings are never cached;
/// recents are never kept here (the review's A7).
pub struct ProjectsCache {
    ttl: Duration,
    entries: Mutex<HashMap<(String, String), Cached>>,
}

impl ProjectsCache {
    pub fn new(ttl: Duration) -> Self {
        Self {
            ttl,
            entries: Mutex::new(HashMap::new()),
        }
    }

    /// The enumeration of `owner`'s `host_id`, filled from connection
    /// `conn_id` less than `ttl` ago.
    pub fn get(&self, owner: &str, host_id: &str, conn_id: u64) -> Option<Enumeration> {
        let entries = self.entries.lock().expect("projects cache lock");
        entries
            .get(&(owner.to_string(), host_id.to_string()))
            .filter(|cached| cached.conn_id == conn_id && cached.at.elapsed() < self.ttl)
            .map(|cached| cached.enumeration.clone())
    }

    pub fn put(&self, owner: &str, host_id: &str, conn_id: u64, enumeration: Enumeration) {
        self.entries.lock().expect("projects cache lock").insert(
            (owner.to_string(), host_id.to_string()),
            Cached {
                conn_id,
                at: Instant::now(),
                enumeration,
            },
        );
    }

    /// Drop every owner's enumeration of `host_id`: it connected again.
    pub fn forget(&self, host_id: &str) {
        self.entries
            .lock()
            .expect("projects cache lock")
            .retain(|(_, host), _| host != host_id);
    }
}

/// keeps them (the review's O5).
fn no_store(body: impl serde::Serialize) -> Response {
    let mut response = Json(body).into_response();
    response
        .headers_mut()
        .insert(header::CACHE_CONTROL, HeaderValue::from_static("no-store"));
    response
}

/// What both routes check before anything is sent, in this order (the
/// review's A7): the host is the owner's (404 `not_found`); connected and
/// reconciled (409 `host_offline`); and it has the `projects` capability
/// (409 `projects_unsupported`). The connection's id, for the cache, or
/// the answer. `Hub::probe` checks the last two again, on the connection it
/// sends on.
fn reachable(state: &AppState, host_id: &str) -> Result<u64, Box<Response>> {
    match state.hosts.host(host_id) {
        Ok(Some(_)) => {}
        Ok(None) => return Err(Box::new(error(StatusCode::NOT_FOUND, "not_found", "no such host"))),
        Err(err) => return Err(Box::new(internal(err))),
    }
    let Some(conn_id) = state.hub.routable_conn(host_id) else {
        return Err(Box::new(probe_failed(RequestError::NotConnected)));
    };
    if !state.hub.has_capability(host_id, Capability::Projects) {
        return Err(Box::new(probe_failed(RequestError::Unsupported)));
    }
    Ok(conn_id)
}

/// The answer to a probe that produced no reply (decision 2).
fn probe_failed(err: RequestError) -> Response {
    match err {
        RequestError::NotConnected => error(StatusCode::CONFLICT, "host_offline", "the host is not connected"),
        RequestError::Unsupported => error(
            StatusCode::CONFLICT,
            "projects_unsupported",
            "this host cannot list or browse projects; update it",
        ),
        RequestError::Busy => busy(),
        RequestError::DeliveryUnknown => error(
            StatusCode::SERVICE_UNAVAILABLE,
            "no_answer",
            "the host did not answer in time",
        ),
        RequestError::Rejected { code, .. } => host_refused(&code),
    }
}

fn busy() -> Response {
    error(StatusCode::SERVICE_UNAVAILABLE, "busy", "the host is busy; try again")
}

fn bad_reply() -> Response {
    error(
        StatusCode::BAD_GATEWAY,
        "bad_reply",
        "the host's answer could not be used",
    )
}

/// A host's refusal (decision 3). Only codes this collector knows are
/// passed on, each with the collector's own message: the host's text is
/// not shown (the review's A6).
fn host_refused(code: &str) -> Response {
    let (status, message) = match code {
        "invalid" => (
            StatusCode::BAD_REQUEST,
            "give an absolute path without `.` or `..` segments",
        ),
        "not_a_directory" => (StatusCode::BAD_REQUEST, "the path is not a directory"),
        "outside_workspace" => (
            StatusCode::FORBIDDEN,
            "the path is outside the host's workspace roots and home directory",
        ),
        "permission_denied" => (StatusCode::FORBIDDEN, "the host may not read this directory"),
        "path_not_found" => (StatusCode::NOT_FOUND, "no such directory on the host"),
        "unreadable" => (StatusCode::BAD_GATEWAY, "the host could not read this directory"),
        "busy" => return busy(),
        _ => return bad_reply(),
    };
    error(status, code, message)
}

/// `GET /api/hosts/{id}/projects`: the repositories under the host's
/// workspace roots (ACP core §7), from the cache or a `list_projects`.
async fn projects(State(state): State<AppState>, Path(host_id): Path<String>) -> Response {
    let conn_id = match reachable(&state, &host_id) {
        Ok(conn_id) => conn_id,
        Err(response) => return *response,
    };
    let owner = state.hosts.owner_id();
    let enumeration = match state.projects.get(owner, &host_id, conn_id) {
        Some(cached) => cached,
        None => {
            let request_id = uuid::Uuid::now_v7().to_string();
            let frame = CollectorFrame::ListProjects {
                request_id: request_id.clone(),
            };
            match state.hub.probe(&host_id, &request_id, frame, state.probe_timeout).await {
                Ok(HostFrame::Projects {
                    items, partial, home, ..
                }) => {
                    let enumeration = checked_enumeration(&host_id, items, partial, home);
                    state.projects.put(owner, &host_id, conn_id, enumeration.clone());
                    enumeration
                }
                Ok(_) => return bad_reply(),
                Err(err) => return probe_failed(err),
            }
        }
    };
    no_store(HostProjects {
        items: enumeration.items,
        partial: enumeration.partial,
        home: enumeration.home,
    })
}

/// A host's enumeration with what cannot be shown left out (the review's
/// A6): paths that are not absolute, too long or hold hidden characters,
/// and any past `MAX_ITEMS`.
fn checked_enumeration(host_id: &str, items: Vec<Project>, partial: bool, home: Option<String>) -> Enumeration {
    let reported = items.len();
    let items: Vec<Project> = items
        .into_iter()
        .filter(|item| is_displayable_path(&item.path))
        .take(MAX_ITEMS)
        .collect();
    if items.len() != reported {
        tracing::warn!(%host_id, dropped = reported - items.len(), "dropped projects that cannot be shown");
    }
    Enumeration {
        partial: partial || reported > MAX_ITEMS,
        items,
        home: home.filter(|home| is_displayable_path(home)),
    }
}

#[derive(Deserialize)]
struct BrowseQuery {
    path: Option<String>,
}

/// Whether `path` is worth asking a host about (decision 3): absolute, at
/// most 4096 bytes, no control character. The host checks the rest.
fn is_askable(path: &str) -> bool {
    path.starts_with('/') && path.len() <= hennery_kernel::hosts::MAX_PATH && !path.chars().any(char::is_control)
}

/// `GET /api/hosts/{id}/browse?path=`: the subdirectories of `path` on the
/// host (ACP core §7), never cached.
async fn browse(
    State(state): State<AppState>,
    Path(host_id): Path<String>,
    Query(query): Query<BrowseQuery>,
) -> Response {
    let Some(path) = query.path.filter(|path| is_askable(path)) else {
        return error(
            StatusCode::BAD_REQUEST,
            "invalid",
            "give `path`: an absolute path of at most 4096 bytes",
        );
    };
    if let Err(response) = reachable(&state, &host_id) {
        return *response;
    }
    let request_id = uuid::Uuid::now_v7().to_string();
    let frame = CollectorFrame::BrowseDirectory {
        request_id: request_id.clone(),
        path,
    };
    match state.hub.probe(&host_id, &request_id, frame, state.probe_timeout).await {
        Ok(HostFrame::Directory {
            path,
            parent,
            entries,
            truncated,
            ..
        }) => match checked_listing(&host_id, path, parent, entries, truncated) {
            Some(listing) => no_store(listing),
            None => bad_reply(),
        },
        Ok(_) => bad_reply(),
        Err(err) => probe_failed(err),
    }
}

/// A host's listing, checked (the review's A6): its path must be
/// displayable, or the answer is refused; a parent that is not is left
/// out, and so are entries whose name is not a plain, displayable file
/// name, and any past `MAX_ENTRIES`.
fn checked_listing(
    host_id: &str,
    path: String,
    parent: Option<String>,
    entries: Vec<DirEntry>,
    truncated: bool,
) -> Option<DirectoryListing> {
    if !is_displayable_path(&path) {
        tracing::warn!(%host_id, "a listing for a path that cannot be shown");
        return None;
    }
    let reported = entries.len();
    let entries: Vec<DirEntry> = entries
        .into_iter()
        .filter(|entry| {
            !entry.name.is_empty()
                && !matches!(entry.name.as_str(), "." | "..")
                && !entry.name.contains('/')
                && is_displayable_text(&entry.name, MAX_NAME)
        })
        .take(MAX_ENTRIES)
        .collect();
    if entries.len() != reported {
        tracing::warn!(%host_id, dropped = reported - entries.len(), "dropped entries that cannot be shown");
    }
    Some(DirectoryListing {
        path,
        parent: parent.filter(|parent| is_displayable_path(parent)),
        truncated: truncated || reported > MAX_ENTRIES,
        entries,
    })
}

async fn start_in(collector: &Collector, host: &mut ScriptedHost, cwd: &str, starts: bool) {
    let (c, url) = (client(collector), format!("http://{}/api/sessions", collector.addr));
    let body = json!({ "host_id": HOST, "agent": "fake", "cwd": cwd });
    let call = tokio::spawn(async move { c.post(url).json(&body).send().await.unwrap().status().as_u16() });
    let CollectorFrame::StartSession {
        request_id, session_id, ..
    } = host.next().await
    else {
        panic!("expected start_session");
    };
    let body = if starts {
        hennery_proto::frames::SessionBody::session_started(request_id, "agent-1")
    } else {
        hennery_proto::frames::SessionBody::StartFailed {
            request_id,
            code: "spawn_failed".into(),
            message: "no".into(),
        }
    };
    host.seq += 1;
    let frame = HostFrame::Session {
        session_id,
        seq: host.seq,
        body,
    };
    host.send(&frame).await;
    assert_eq!(call.await.unwrap(), if starts { 202 } else { 502 });

//! Project recents (kernel spec §1.1, §5.3; plan 6c decision 11): the
//! directories sessions started or resumed in, per host and hat, newest
//! first. They share the host registry's connection and owner, and every
//! query names the owner (kernel spec §1).

use crate::hats::{is_canonical, resolve};
use crate::hosts::{Hosts, is_displayable_path};
use anyhow::Result;
use rusqlite::{TransactionBehavior, params};
use std::collections::HashSet;

/// The recents kept per host and hat; older ones are dropped.
pub const KEPT: usize = 50;

/// The recents the project picker shows.
pub const SHOWN: usize = 20;

/// One recent project.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Recent {
    pub path: String,
    /// Seconds since the Unix epoch.
    pub last_used_at: i64,
}

impl Hosts {
    /// Remember that a session of `hat_id` started or resumed in `path` on
    /// `host_id` at `now`, keeping the newest `KEPT` of that host and hat.
    /// `false`, and nothing remembered, for a path that is not canonical or
    /// cannot be shown: until the host resolves a session's cwd (hats 5b),
    /// it is what its client sent.
    pub fn remember(&self, host_id: &str, hat_id: &str, path: &str, now: i64) -> Result<bool> {
        if !is_canonical(path) || !is_displayable_path(path) {
            return Ok(false);
        }
        let owner = self.owner_id();
        let mut conn = self.conn();
        let tx = conn.transaction_with_behavior(TransactionBehavior::Immediate)?;
        tx.execute(
            "INSERT INTO project_recents(owner_id, host_id, hat_id, path, last_used_at) VALUES (?1, ?2, ?3, ?4, ?5)
             ON CONFLICT(host_id, hat_id, path) DO UPDATE SET last_used_at = excluded.last_used_at
                 WHERE project_recents.owner_id = ?1",
            params![owner, host_id, hat_id, path, now],
        )?;
        tx.execute(
            "DELETE FROM project_recents WHERE owner_id = ?1 AND host_id = ?2 AND hat_id = ?3 AND path NOT IN (
                 SELECT path FROM project_recents WHERE owner_id = ?1 AND host_id = ?2 AND hat_id = ?3
                 ORDER BY last_used_at DESC, path LIMIT ?4)",
            params![owner, host_id, hat_id, KEPT as i64],
        )?;
        tx.commit()?;
        Ok(true)
    }

    /// The newest `limit` recents of `host_id` whose path resolves to
    /// `hat_id` now (kernel spec §5.3; the review's A1): resolved against
    /// the host's current rules and default hat, not the hat stored when
    /// each was remembered, which a rule or a default changed since leaves
    /// stale. Empty for an unknown host.
    pub fn recents(&self, host_id: &str, hat_id: &str, limit: usize) -> Result<Vec<Recent>> {
        let (Some(rules), Some(host)) = (self.path_rules(host_id)?, self.host(host_id)?) else {
            return Ok(Vec::new());
        };
        let conn = self.conn();
        let mut stmt = conn.prepare(
            "SELECT path, last_used_at FROM project_recents WHERE owner_id = ?1 AND host_id = ?2
             ORDER BY last_used_at DESC, path",
        )?;
        let rows = stmt.query_map(params![self.owner_id(), host_id], |r| {
            Ok(Recent {
                path: r.get(0)?,
                last_used_at: r.get(1)?,
            })
        })?;
        let mut seen = HashSet::new();
        let mut shown = Vec::new();
        for recent in rows {
            let recent = recent?;
            // Newest first, so a path stored under two hats is shown once,
            // with its latest use.
            if resolve(&rules, &host.default_hat_id, &recent.path).hat_id == hat_id && seen.insert(recent.path.clone())
            {
                shown.push(recent);
                if shown.len() == limit {
                    break;
                }
            }
        }
        Ok(shown)
    }
}
